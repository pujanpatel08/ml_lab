# Module 02: PyTorch basics

Open `pytorch_basics.ipynb` and work through it top to bottom. It covers tensors and shapes, broadcasting, matrix multiplication, using your Mac's GPU (MPS), autograd, and the training loop. It ends with a small neural network learning `sin(x)` on your GPU.

Before you start, make sure `matplotlib` is installed (`uv add matplotlib`, from module 00).

If the linear algebra feels shaky, watch the first four episodes of 3Blue1Brown's "Essence of Linear Algebra" first. Matrix multiplication as "transforming space" is the intuition you want.

You're done with this module when you can do all five exercises without looking at the solutions, and when you can explain from memory what each of the five lines in a training loop does.

Official reference, for when you want more: the "Learn the Basics" tutorial at pytorch.org/tutorials.
